# HW Live Test 0.3.16

Улучшены графики, запись сигналов и включение управления устройством.
Выпуск объединяет локальные пробные версии 0.3.14–0.3.16.

## Изменения

- Контрастные цвета для обеих тем назначаются по порядку отметок: синий, красный,
  зелёный, охра, фиолетовый, бирюзовый. Последний отмеченный канал рисуется сверху.
  Выделение линии для просмотра значения не меняет порядок слоёв.
- В выборе каналов есть поиск, фильтр «Выбранные» и счётчик результатов.
  Фильтр сохраняет отметки. Выбор каналов и шкалы запоминаются для таблицы.
- Исправлены мигание статуса свежести и смещение названий сигналов.
  Одинаковые короткие имена различаются по пути топика.
- Кнопка «Запись» сохраняет MCAP; формат указан в настройках. Вверху экрана
  показываются состояние записи, длительность и размер файла.
- Экран не гаснет при просмотре графиков и записи. Пауза графика не останавливает
  опрос и запись. Поворот сохраняет запись; уход с экрана завершает её.
- Буфер графиков можно сохранить отдельно. Потеря связи сохраняет видимые данные;
  новое подключение очищает историю.
- Включение «Доступа» при необходимости подключается к устройству без запуска
  проверки платы. Потеря соединения выключает доступ.
- Последний файл прошивки восстанавливается при сохранённом разрешении Android.
- Журнал различает запросы пользователя, результаты и автоматические события.
  «ПУСК» заменён на «Проверить плату» в интерфейсе и подсказках.
- «О программе» проверяет опубликованный релиз GitHub и предлагает открыть его,
  если версия новее установленной.
- Уточнены техническое описание сайта и README.

## Ограничения

- Формат записи сейчас только MCAP (ROS 1).
- Проверка обновлений требует интернета; APK устанавливается пользователем.
- Логический анализатор остаётся отложенным.
- Option bytes и защита Flash не изменяются.
