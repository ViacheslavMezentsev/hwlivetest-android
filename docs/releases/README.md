# Описания релизов

Для каждой версии хранится файл `<версия>.md`: пользовательские изменения, имя APK,
результаты проверок и известные ограничения. Его содержимое используется как описание
соответствующего GitHub Release.

Теги создаёт и публикует только владелец. Перед тегом ветка должна пройти CI и быть
влита в main обычным циклом push → land. Агент готовит описание и проверенный APK;
публикует GitHub Release только по прямому поручению владельца и для уже существующего
тега. Версия тега и исходный код APK должны соответствовать друг другу. Переподпись
коммитов меняет SHA: соответствие исходников проверяется по дереву Git.

Если после сборки менялась только документация, повторная сборка не обязательна:
в описании сохраняется фактический коммит, указанный внутри APK.
