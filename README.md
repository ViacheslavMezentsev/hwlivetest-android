# HW Live Test (Android)

Работа с платой, на которой работает прошивка, прямо с телефона: подключаете ST-Link
к телефону через OTG — приложение опознаёт адаптер и микроконтроллер и читает память
на ходу. Без Termux, OpenOCD и GDB: протокол ST-Link реализован на Kotlin поверх
Android USB Host API.

## Что умеет (только чтение)

**Простой режим** — одна кнопка «ПУСК»: приложение подключается к ST-Link, опознаёт MCU
и проверяет, жив ли он, выполняет ли код, не завис ли в обработчике сбоя, есть ли
прошивка, защищена ли Flash и от чего он тактируется (подробно для STM32F1, F4, G4 —
см. [эвристики](docs/heuristics.md)). Потом доступны резервная копия Flash в Intel HEX
и сверка с HEX. **Режим эксперта** (меню) — всё ниже:

- находит ST-Link V2 (`0483:3748`), V2-1 (`0483:374B`, `0483:3752`),
  V3 (`0483:374E`, `0483:374F`, `0483:3753`, `0483:3754`) и запрашивает разрешение USB;
- показывает версию прошивки адаптера и напряжение цели, входит в SWD;
- опознаёт MCU: DP IDCODE, CPUID (ядро и ревизия), производителя по ROM-таблице
  (PIDR, JEP106), для STM32 — DBGMCU_IDCODE и размер Flash, для AT32 — PID;
- читает 32-битное слово по введённому адресу;
- загружает список полей из `addresses.json` и показывает их значения на ходу;
- рисует графики одного или нескольких полей за 30 с, 1 мин или 5 мин (опрос 10 Гц,
  соседние поля — одним блоком READMEM_32BIT), со средним на оси и общей или своей
  шкалой; порядок слоёв — порядок отметки полей;
- пишет выбранные поля в MCAP (ROS 1 `std_msgs`, открывается в Foxglove и PlotJuggler)
  и экспортирует последние 5 минут; файл можно сразу отправить, например в Telegram;
- в шапке каждого экрана — дата и время до секунды (видно на снимках экрана);
- пишет подробный журнал обмена (его можно скопировать и прислать).

Микроконтроллер не останавливается и не сбрасывается, в память ничего не пишется.

Дальше: rosbag, логический анализатор WeAct LogicAnalyzerV1 (FX2).

## Поля из addresses.json

Файл создаёт `resolve_addresses.py` из комплекта навыка `stm32-diag-record` (адреса
считаются по ELF). Приложение читает только массив `fields`, остальным ключам доверяет:

| Ключ | Как используется |
|---|---|
| `topic` | имя поля, ключ (повторы пропускаются) |
| `kind` | `float32`, `uint32`, `int32`, `uint32_seconds`; иначе читается как `uint32` |
| `address` или `address_hex` | адрес слова, должен быть выровнен на 4 |
| `min`, `max` | значения вне границ показываются красным и не попадают на график |
| `shift`, `mask` | поля регистров SVD: `(слово & mask) >> shift` |
| `expr` | показывается на экране графика |

Адреса сверяются с размерами Flash и SRAM опознанного MCU; выход за пределы и
регистры периферии отмечаются предупреждением, но не блокируются. Последний открытый
файл запоминается.

## Сборка

Нужны JDK 17+ и Android SDK (проще всего — Android Studio).

```shell
./gradlew test assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Готовый отладочный APK также лежит
в артефактах каждого запуска GitHub Actions (вкладка Actions → запуск → Artifacts).

## Установка

```shell
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

или скопируйте APK на телефон и откройте его (нужно разрешить установку из этого
источника). Затем подключите ST-Link через OTG-переходник, согласитесь открыть
HW Live Test и выдайте доступ к USB.

## Модули

| Модуль     | Назначение                                                  |
|------------|-------------------------------------------------------------|
| `stlink`   | протокол ST-Link и опознание Cortex-M (Kotlin/JVM, тесты)   |
| `usb`      | поиск адаптеров, разрешения, bulk-транспорт (Android)       |
| `app`      | экраны                                                      |
| `fx2la`    | задел: логический анализатор на FX2                         |
| `recorder` | запись MCAP (ROS 1 `std_msgs`, Kotlin/JVM)                  |
| `telemetry`| поля addresses.json, опрос, ряды, оси графика (Kotlin/JVM)  |
| `diag`     | эвристики кнопки «ПУСК» (Kotlin/JVM)                        |
| `firmware` | Intel HEX, резервная копия и сверка Flash (Kotlin/JVM)      |
