# Записи обмена с ST-Link

Формат совпадает с журналом приложения (кнопка «Копировать журнал»):

- `> f2 36 00 ed 00 e0` — команда (хвостовые нули опущены, дополняется до 16 байт);
- `< 80 00 00 00 31 c2 1f 41` — ответ адаптера;
- строки, начинающиеся с `#`, и прочие строки журнала игнорируются.

Файлы с префиксом `synthetic-` составлены по описанию протокола (OpenOCD `stlink_usb.c`)
и известным значениям регистров. После аппаратной проверки рядом кладутся настоящие
записи с телефона (`phone-*.txt`).

Перед коммитом убедитесь, что в записи нет серийных номеров и UID микроконтроллера.
